# How Robots Think: code

Runnable code for the science in each *How Robots Think* video: one folder per video, each with a notebook that runs
on a laptop or in Colab.

| video | what is inside | run |
|---|---|---|
| [Full glass](upkie-full-glass/) | LQR vs MPC on Upkie, an open-source wheeled biped carrying a full glass, in MuJoCo | [Open in Colab](https://colab.research.google.com/github/how-robots-think/code/blob/main/upkie-full-glass/upkie_full_glass.ipynb) |
